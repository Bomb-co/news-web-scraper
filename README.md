# News Web Scraper
This project is a simple Python web scraper that collects news titles and links from Hacker News.

## Features
- Scrapes news titles
- Extracts news links
- Saves data into CSV file

## Technologies Used
- Python
- Requests
- BeautifulSoup
- Pandas

## Output Example
title,link
AI startup raises funding,https://example.com
Python new release,https://example.com

## How to Run
1. Install dependencies
pip install requests beautifulsoup4 pandas

2. Run the script
python news_scraper.py
